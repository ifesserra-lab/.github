### 🌟 Nosso Propósito
Nossos repositórios abrigam soluções desenvolvidas para impactar positivamente o **dia a dia do Campus Serra**. Acreditamos que a tecnologia é a ponte para uma comunidade acadêmica mais eficiente e conectada.

### 🚀 Projeto em Destaque: **Horizon**
O projeto **Horizon** exemplifica como usamos engenharia de dados para transformar o campus:
- **Funcionalidade:** Extração e centralização de dados acadêmicos (ETL).
- **Impacto:** Gera inteligência sobre grupos de pesquisa e editais para alunos e gestores.
- **Stack:** [Prefect](https://www.prefect.io/), [Python](https://www.python.org/), [Docker](https://www.docker.com/).
